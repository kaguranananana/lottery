## 2026-11-12 · 实时 Outbox 首发写入优化

- 库存首发代数随 TX2 落库，发奖首发代数随库存终态 CAS 落库。两条实时路径不再额外执行领取 UPDATE，保留到期补偿、租期、结果代数 CAS 和唯一结算账本。无需 Schema 迁移。
- 零换页的 150 RPS 301 秒基线出现 1,045 次 Outbox 容量拒绝，首尾积压增长 215.57 单，15.28 秒排空，未通过稳定性门槛。相同负载优化后完成 149.87 笔抽奖/秒，库存 P95/P99 上界为 470/937 ms，拒绝 19 次，0.29 秒排空。120 RPS 持续 195 秒通过，默认限流下 350 RPS 突发稳定保护。
- Java 8 默认 53 项、独立中间件及 SQL 80 项通过。真实进程在 TX2 提交后、发送前退出，复演重启后约 2.15 秒恢复，原订单、额度和账本一致。持久日志和热行竞争仍会短时用满连接池，尚未验证更高的不限流持续档位。 [实测报告](single-db-load-test.md)
