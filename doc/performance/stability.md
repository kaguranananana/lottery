# 本次稳定性判断（定速持续测试前固定）

闭环并发阶梯用于观察响应与过载，不等同持续容量。完整业务链路的稳定候选至少测量180秒，最高候选再持续300秒。

- 实际新抽奖完成速率达到目标到达速率的95%以上；HTTP与系统错误率小于0.1%，正常基准不含拒绝或回放。
- HTTP P99低于1000ms；没有OOM、任务异常、连接超时或库存/订单/账本审计失败。
- 采样未完成发奖订单的峰值不超过10秒请求量；最后60秒平均积压相比最初60秒增长不超过1秒请求量，避免把缓慢增长误称为稳定。
- HTTP返回后异步完成P95的保守上界低于10秒；停止HTTP后15秒内全部结算/本地模拟发奖完成，Kafka Lag归零。

以上是本次本地测试的验收阈值，不是既有生产SLA。最大稳定吞吐是已实测通过这些条件的最高请求速率。未测速率不作保证；若最高通过速率与较高失败速率之间仍有间隔，明确给出该区间。
