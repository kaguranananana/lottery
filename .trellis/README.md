# Lottery 的 Trellis 资料说明

Trellis 的任务、阶段流程和旧 workspace 日志保留为历史材料，不作为日常开发门槛。当前开发约定与记录方式见根目录 `AGENTS.md`、`docs/PROJECT_STATUS.md` 和 `docs/DEVLOG.md`。

## 保留的技能

- `project-memory`：恢复项目当前状态，并记录有实质内容的开发、调试和评估进展。
- `trellis-session-insight`：按需追溯历史 Agent 会话。
- `trellis-spec-bootstrap`：仅在需要重建或刷新项目规范时使用。
- `trellis-update-spec`：在发现长期有效的新约定、技术决定或故障预防经验时复核并更新规范。

## 历史资料

- `workflow.md` 保留原 Trellis 流程，文件开头已标记为停用。
- `tasks/archive/` 保存旧任务材料；`workspace/` 保存既有开发者 journal。
- `.trellis/spec/` 仍是项目编码规范与技术上下文的存放位置。
- `scripts/` 仍可用于查询或维护历史 Trellis task 和 journal；新开发记录默认写入 `docs/PROJECT_STATUS.md` 与 `docs/DEVLOG.md`。
