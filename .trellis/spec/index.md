# Lottery 开发规范

本规范依据当前 Maven 模块、实际源码、现有测试、[README.md](../../README.md) 与 [architecture.md](../../docs/architecture.md) 初始化。文档中的「现状」与「已知边界」描述已有行为；后续改动遵循 [AGENTS.md](../../AGENTS.md) 的根因优先原则。

| 文档 | 用途 |
| --- | --- |
| [项目上下文](./project-context.md) | 技术栈、模块依赖、主链路、运行环境与已知限制 |
| [后端规范](./backend/index.md) | HTTP、应用、领域、数据库、Redis、日志与质量要求 |
| [跨层指南](./guides/index.md) | 字段流转与现有能力复用 |

本仓库是同一 Lottery 服务的五个 Maven 模块，统一使用 backend 规范；不为每个模块复制一套模板。当前仓库没有前端源码，页面与网关不在本规范管理范围。相邻仓库的路由组件与部署栈仅作为外部依赖。

开始任务时先读项目上下文和后端索引，再阅读涉及的主题。新发现的接口契约、真实故障或架构决定，应在任务结束前更新对应规范及索引。
